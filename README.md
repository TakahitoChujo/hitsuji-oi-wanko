# ひつじ追いワンコ

**うちの子が、牧羊犬になる。** 犬を操って、牧場に散らばった羊を小屋に追い込むブラウザゲームです。全部入れたら、最後にゲートを閉めてクリア。全5ステージ。

**遊ぶ:** https://takahitochujo.github.io/hitsuji-oi-wanko/

インストール不要で、パソコンでもスマホでも遊べます。

## うちの子を主人公にする

タイトル画面の「うちの子の写真を使う」か、ステージ1をクリアしたときに出るお誘いから写真を選んで、顔を丸の中に合わせると、その子が主人公になります。

「見た目を整える」（うちの子メーカー）で、毛色・模様の色・模様（なし／胸が白／くつした／ぶち／背中だけ）・耳（立ち耳／垂れ耳）・しっぽ（巻き尾／まっすぐ／ふさふさ／短い）・体格（小型／中型／大型）を選べます。毛色は「写真から」を選ぶと写真から自動で決まります。体格は見た目と鳴き声の高さだけが変わり、速さや強さは同じです。名前も付けられて、クリア画面で「ポチは一人前の牧羊犬！」のように表示されます。

写真は、遊んでいる端末の中で160×160ピクセルに縮めてから保存します。サーバーには送信しません（下の「プライバシー」を参照）。

## ステージ

| # | ステージ | 羊 | しかけ |
|---|---|---|---|
| 1 | はじめての牧場 | 6頭 | 練習用 |
| 2 | 木立の牧場 | 11頭（リーダー羊つき） | 木と岩 |
| 3 | ぬかるみ | 10頭（黒羊2頭） | 足が遅くなるぬかるみ |
| 4 | 川と橋 | 10頭（子羊2頭） | 川をわたれるのは橋だけ |
| 5 | 夕暮れの大放牧 | 16頭（全種類） | ぬかるみ、夕暮れ |

前のステージをクリアすると、次のステージで遊べるようになります。

### 羊の種類

- **ふつうの羊**：犬から逃げて、仲間と固まろうとする
- **リーダー羊**（ベルつき）：まわりの羊がついていく。この羊を誘導すると早い
- **黒羊**：頑固で、歩いて近づいてもなかなか動かない。ワン！が効く
- **子羊**：お母さん羊のそばを離れない
- **臆病な羊**：すぐパニックになって、群れから離れて走り出す。ふせでそっと押すのがコツ

### ★評価とお題

- ★：クリア
- ★：目標タイム以内
- ★：ステージの「お題」を達成

タイムとお題は別々に取れます。お題は操作の使い分けを覚えるためのもので、クリアには必要ありません。

| # | お題 |
|---|---|
| 1 | ワン！を使わずにクリア |
| 2 | リーダー羊を一番最初に小屋に入れる |
| 3 | ワン！3回以内でクリア |
| 4 | 羊のパニック8回以内でクリア |
| 5 | 臆病な羊を一度もパニックにさせずにクリア |

ランクはそのプレイの★の数で決まります（★1 見習いワンコ／★2 一人前の牧羊犬／★3 チャンピオン牧羊犬）。

## 遊び方

| 操作 | パソコン | スマホ |
|---|---|---|
| 移動 | マウスを動かす／矢印キー・WASD | 画面を押して、行きたい方向へスライド |
| ワン！（ほえる） | 右クリック／スペース | ワン！ボタン |
| ふせ（にらみ） | 左クリックかShiftを押している間 | ふせボタンを押している間 |
| ゲートを開け閉め | 入口のそばでEキー | 入口のそばでゲートボタン |
| 一時停止 | 一時停止ボタン／P・Escキー | 一時停止ボタン |

アプリやタブを切り替えると、自動で一時停止します。音のON/OFFとやり直しは、一時停止メニューの中にあります。

- **ワン！** を使うと、近くの羊がいっせいに走ります。そのぶん群れはバラけやすくなります。
- **ふせ** の間は、羊を落ち着かせたまま、ゆっくり押せます。本物の牧羊犬が使う「アイ（にらみ）」という技がもとになっています。
- 勢いよく突っ込むと羊はパニックになり、ゆっくり近づくと落ち着いたまま歩きます（スマホはスティックを少しだけ倒す）。
- ワン！は毎回少しずつ鳴き声が変わります。効果はいつも同じです。
- ゲートが開いているうちは、小屋に入った羊が外へ出ていくことがあります。

## 音

遊んでいる間だけ、牧場の BGM が流れます（音声ファイルは使わず、ブラウザの中で鳴らしています）。一時停止メニューの「音」で、BGM と効果音をまとめてオフにできます。

## 結果のシェア

クリア画面の「結果をシェア」で、犬の顔と全身の姿・ランク・★・タイムの入った画像を作ります。スマホでは端末の共有メニュー（LINE、X、Instagram など）が開きます。共有メニューがない環境では、画像の保存、X へのポスト、LINE で送る、文章のコピーができる画面が開きます。

## ファイル構成

```
index.html            ページ本体（リンクを貼ったときのプレビュー設定を含む）
style.css             見た目
game.js               ゲームの処理（ライブラリは使っていません）
favicon.svg           タブに出るアイコン
apple-touch-icon.png  ホーム画面に追加したときのアイコン
og.png                リンクを貼ったときに出る画像（1200×630）
```

ビルドの手順はありません。`index.html` をブラウザで開けばそのまま動きます。

## プライバシー

- ゲームが外部へデータを送ることはありません。ベストタイム、★、音のON/OFF、主人公の名前と写真（縮小版）と見た目の設定は、遊んでいる人のブラウザの中（localStorage）にだけ保存されます。「写真を外す」を押すと、写真は消えます。
- 写真の読み込みと切り抜きは、すべてブラウザの中で行います。Content-Security-Policy で外部への通信（`connect-src`）を禁止しているので、仕組みのうえでも送信できません。
- 「結果をシェア」で作る画像には、主人公の写真が入ります。画像は遊んでいる人が自分で共有先を選んで送るもので、ゲームがどこかへアップロードすることはありません。
- フォントは Google Fonts から読み込んでいます。そのため、遊んだ人のIPアドレスが Google に送られます。
- Content-Security-Policy で、読み込める外部サイトを Google Fonts だけに制限しています。

## GitHub Pages での公開

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、Branch を `main`、フォルダを `/ (root)` にして保存する
3. 1〜2分待つと `https://takahitochujo.github.io/hitsuji-oi-wanko/` で遊べるようになる

更新するときは、`index.html` の `style.css?v=` と `game.js?v=` の番号を上げてください。上げ忘れると、ブラウザに残った古いファイルが読み込まれることがあります。
